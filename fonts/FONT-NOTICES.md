## OpenDyslexic (OFL-OpenDyslexic.txt)

Copyright (c) Abbie Gonzalez, https://opendyslexic.org, with Reserved
Font Name "OpenDyslexic".

The upstream project publishes OTF (CFF-outline) builds only. The .ttf
files here were converted from the official OTFs to TrueType outlines
for one technical reason: ReportLab, which builds the PDF output, can
only embed TrueType. The conversion changes the outline format and
nothing else: no glyphs, metrics, or design were altered. Under a strict
reading of the OFL, a format conversion is a Modified Version, and
Modified Versions should not carry the Reserved Font Name; permission
from the author to keep the OpenDyslexic name on these format-converted
files has been requested. If you prefer the untouched originals, they
live at https://github.com/antijingoist/opendyslexic.
